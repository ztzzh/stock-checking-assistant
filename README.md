# 股票筛选助手 · Windows桌面版

本仓库只发布桌面EXE版。下载完整分发包后，解压并双击 `股票筛选.exe`。

**[下载桌面版完整包](https://github.com/ztzzh/stock-checking-assistant/releases/latest)**

请下载 Release 中的 `StockCheckingAssistant-v版本-win-x64.zip`，不要只下载单个EXE或GitHub自动生成的Source code压缩包。EXE需要同目录的后端与运行文件；完整包已携带Node.js、浏览器和固定版本依赖，无需另外配置Node或Playwright。

## 使用

1. 将完整ZIP解压到可写目录，保留文件夹结构。支持中文、空格和移动目录。
2. 双击根目录的 `股票筛选.exe`。需要桌面入口时，为它创建快捷方式。
3. 选择东方财富或新浪财经，填入/点选当天人工选好的板块。
4. 选择复核模型、审核路数和纳入范围，点击“开始选股”。
5. 运行时可暂停，点“继续”接着同一任务剩余队列执行；也可停止并保存，稍后从“继续任务”补缺项。

行情与模型服务需要联网。选择Sol/Terra/Luna时，本机须安装并登录可用的Codex；选择DeepSeek或千问时，填写自己的API密钥和相应地址。密钥仅本次使用，不保存在设置里。网站要求人工验证时，在浏览器完成后点“完成，继续”。

## 功能与策略

- 新浪/东方财富来源切换，六路独立采图；采图与审核并行。
- Sol、Terra、Luna、DeepSeek和千问；审核并发下拉选择；主图优先、必要时补证、裁边试用。
- 手工指定行业/概念，按只数、全部或百分比纳入；去重后每只股票只处理一次。
- 可见现价高于今开后，按顺序看15分钟图：厂字形 → 回踩MA20 → MA20高于MA60 → 红量占优。身份、实际周期、日期、均线或量柱证据不清时保留待审核。
- 右侧实时显示符合股票，可复制名称；已复制标记和深色底色在本轮刷新、暂停、继续时保留。
- 暂停停止新任务分配，已在途工作返回保存后停下；暂停等待不消耗执行预算。

桌面归档：`桌面/股票/当天日期/任务名_时间/`。每个任务根目录只放 `结果.csv`、符合股票的15分钟主图（股票名命名）和 `其他/`。中断记录、淘汰/待审核图、判定说明与原始证据保留在“其他”。

这是截图筛选工具；仅“符合”才表示本轮四项图形规则通过，待审核和未完成项不可算成通过。不执行交易。

## 仓库内容

| 路径 | 用途 |
| --- | --- |
| `股票筛选.exe`、`gui/` | 桌面入口及可构建的C#源码 |
| `script/` | EXE调用的共享后端、队列、采图、审核和归档逻辑 |
| `extension/core.js`、`extension/visible.js` | 仍被桌面后端引用的校验/可见DOM读取代码；没有浏览器插件入口 |
| `rendered-full-page.mjs` | 与截图配套的页面读取代码 |
| `vendor/` | 固定版本依赖源码包及校验记录，便于离线安装 |
| `tools/`、`tests/` | 打包、发布审计和测试 |

旧CMD/PowerShell选股入口、Web工作台、Web服务器、历史截图结果、浏览器登录资料和个人配置未上传。共享后端保留完整，未通过删模块裁掉桌面功能。
