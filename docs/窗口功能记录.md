# 桌面窗口功能

行情来源在左侧选择东方财富或新浪。板块表格可增删改，单击底色选入本轮，每天由使用者人工确认板块。

正常选股会核对指定板块并读取成分名单；不会遍历全市场历史排行。全部成分和百分比范围支持大名单；跨板块重复股票只处理一次。

运行方式包括正常选股、继续任务、仅复核截图、预览成分、只采截图。原任务可以选择项目批次或桌面归档目录；原图复核沿用截图时点，继续任务保留原名单和已完成项。

任务名可空，自动使用板块名和时间。采集与复核预算分开计算，人工验证及用户暂停等待不消耗相应执行预算。

采图固定六路；审核路数可选。采图和审核独立并行，队列过长会暂停分配新股票。图证默认主图优先，证据缺项可补必要图一次；裁边是可选试用，不会覆盖原图。

模型包括Sol、Terra、Luna、DeepSeek、千问。千问具体型号和Base URL可选择/修改；实时、翻译专用型号保留用途提示，不能当作普通截图审核接口使用。Codex使用本机登录；API密钥只在本次窗口内使用。

本轮符合逐行显示股票名和代码。复制只复制股票名；成功后显示已复制和深灰蓝底色，新增股票、重排、暂停及继续不清除本轮标记。

运行时按钮为暂停，请求后停止新增工作，在途图证及审核保存后已暂停。继续从同一任务剩余部分执行；人工验证时仍为完成，继续。停止并保存会保留缺项，结束后可使用继续任务恢复。

结果位置为桌面/股票/当天日期/任务名_时间。根目录仅结果.csv、符合股票15分钟主图和其他文件夹。其他中保留淘汰、待审核图、说明、诊断和原始记录。打开结果文件夹按钮打开桌面股票根目录。
